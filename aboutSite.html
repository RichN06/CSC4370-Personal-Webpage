Why I Created This Site

I created this website for the sake of learning and improving on my web programming skills. Rather than creating tiny 1-paged websites to learn a specific skill or concept, I'm putting everything on this website to record my progression as a web developer and see the growth for over this semester. This website is more of a tracking record for everything that I have learned, as well as a sandbox for assets that could potentially be useful in the future.

Motivation & Vision

My main motivation comes from a passion for software development, system design, and user experience. Seeing how raw code transforms into structured, interactive digital tools drives me to keep experimenting with front-end technologies and expanding my overall programming toolset. This is an extremely flexible field that is found almost everywhere in the world for a variety of applications. By mastering this skill, it can become a valuable commodity for myself in the future, where I could apply it countless of different scenarios, whether that would be creating a website for advertisement, a central hub, the possibilites are endless.
